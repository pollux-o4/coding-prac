# 2026-07-02 - Array - 개념 소개

## 1. 학습 범위

진행한 체크포인트: Week 1, Day 3-5 - Array, 개념 단계 (언어 로테이션 규칙에
따라 Python 구현보다 먼저). 이번 세션은 가이드 Q&A로 배열의 핵심 개념을
다뤘다: 연속 메모리 저장, 인덱스 기반 O(1) 조회/수정, 중간 삽입/삭제가
O(n)인 이유(뒤 원소를 밀거나 당겨야 함), 그리고 이 트레이드오프가 실무
선택(조회 위주 vs. 삽입/삭제 위주)에 미치는 영향.

## 2. 막힌 점 / 헷갈린 점

- 배열을 "순서가 있을 수도 없을 수도 있는 데이터 모음"으로 처음 정의함 -
  배열은 항상 순서(인덱스)가 있고 메모리에 연속으로 저장된다는 점으로
  정정.
- "삽입"을 "이미 있는 자리에 값을 덮어쓰는 것"으로 오해함 (그래서 처음엔
  삽입도 O(1)이라 판단) - 삽입은 기존 값을 지우지 않고 끼워 넣는 것이라
  뒤 원소가 한 칸씩 밀려나야 하고, 그래서 O(n)이라는 점으로 정정.
- 삽입/삭제가 잦은 상황(예: 대기열)에 배열보다 나은 구조가 있는지 질문함 -
  Linked List가 더 유리하다는 점만 짚어주고, 아직 배우지 않은 주제라 상세
  설명은 다음 체크포인트로 미룸 (just-in-time 생성 원칙에 따름).
