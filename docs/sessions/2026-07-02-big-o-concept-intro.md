# 2026-07-02 - Big O - 개념 도입

## 1. 학습 범위

진행한 체크포인트: Week 1, Day 1-2 - "Big O 표기법과 메모리 모델"
(구조별 학습에 들어가기 전, 커리큘럼의 첫 체크포인트). 이번 세션은 Q&A
방식으로 Big O 절반을 마쳤다: O(1), O(n), O(n^2), O(n^3), O(log n)(이진
탐색으로), O(n log n)(병합정렬 및 "n개 각각에 이진 탐색" 패턴으로). 이
체크포인트의 메모리 모델 절반은 이번 세션에서 다루지 않았다.

## 2. 막힌 점 / 헷갈린 점

- 처음엔 "이진(binary) 탐색"이 0/1 값을 다루는 것이라고 생각했음 - "탐색
  범위를 반으로 줄인다"는 뜻으로 정정. 1~100 숫자 맞히기 게임 비유로 바로잡음.
- 처음엔 O(n log n)을 "배열 한 번 도는 안에 범위를 반으로 쪼개는 작업이
  포함된 것"으로 이해했는데, 이는 병합정렬의 실제 구조("log n개 레벨,
  각 레벨마다 n개 전체를 훑음")와는 다름. 학습자가 말한 그림 자체는 다른
  패턴(n개 각각을 이진 탐색하는 경우)에는 정확히 들어맞는다고 확인해줬고,
  병합정렬은 구조는 다르지만 결과적으로 같은 n log n이 나온다고 짚어줌.
- Big O도 직접 코드로 실습해야 하는지 질문함. Big O 자체는 데이터구조처럼
  "구현"할 대상이 아니라, 실제 코드를 보고 복잡도를 판별하는 연습이 실습에
  해당한다고 정리함. 그 실습은 다음 체크포인트로 미룸.

## 4. 다음 스텝

주제: Big O 표기법과 메모리 모델. 다음 산출물: (a) 이 체크포인트의 메모리
모델 절반(스택 vs 힙, 변수/배열이 어떻게 저장되는지) 다루기, (b) 학습자가
실제 코드 스니펫 여러 개의 Big O를 분류해보는 짧은 실습(또는 입력 크기별로
O(n)과 O(n^2)의 연산 횟수를 비교해보기). 완료 기준: 메모리 모델을 학습자
본인 언어로 설명할 수 있고, 코드 스니펫 최소 3개를 올바르게 Big O로 분류할
것 - 그 다음에야 Array(Week 1, Day 3-5)로 넘어감.
