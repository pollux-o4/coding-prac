# 도메인 문서

엔지니어링 스킬이 이 레포를 탐색할 때 도메인 문서를 어떻게 소비해야 하는지에 대한 규칙.

## 탐색 전에 다음을 읽는다

- 레포 루트의 **`CONTEXT.md`**.
- **`docs/adr/`** — 작업할 영역과 관련된 ADR.

이 파일들이 없으면 **조용히 진행한다**. 부재를 별도로 알리지 말고, 미리 만들자고 제안하지도 말 것. 생성 스킬 (`/grill-with-docs`) 이 용어나 결정이 실제로 정리될 때 lazy 하게 만든다.

## 파일 구조

이 레포는 단일 컨텍스트 레이아웃을 쓴다.

```text
/
|-- CONTEXT.md
|-- docs/
|   `-- adr/
`-- ...
```

## 용어 사전의 어휘를 쓴다

이슈 제목, 제안, 가설, 테스트 이름에서 도메인 개념을 명명할 때 `CONTEXT.md` 에 정의된 용어를 그대로 쓴다. 용어 사전이 명시적으로 피하라고 한 동의어로 흘러가지 말 것.

필요한 개념이 아직 용어 사전에 없으면, 그 표현이 이 프로젝트의 언어에 속하는지 재검토하거나 `/grill-with-docs` 가 메울 수 있게 빈자리를 기록한다.

## ADR 충돌은 명시적으로 알린다

결과물이 기존 ADR 과 모순되면, 조용히 덮어쓰지 말고 명시적으로 끌어올린다.
