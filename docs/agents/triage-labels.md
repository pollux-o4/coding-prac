# 트리아지 라벨

스킬은 다섯 가지 정규 트리아지 역할의 이름을 쓴다. 이 파일은 그 역할을 이 레포의 이슈 트래커에서 실제로 쓰는 라벨 문자열로 매핑한다.

| mattpocock/skills 라벨 | 이 트래커의 라벨              | 의미                                  |
| -------------------------- | --------------------------------- | ---------------------------------------- |
| `needs-triage`             | `분류 필요 (needs-triage)`        | 메인테이너가 이 이슈를 평가해야 함  |
| `needs-info`               | `정보 필요 (needs-info)`          | 추가 정보를 위해 보고자를 기다림 |
| `ready-for-agent`          | `에이전트 준비 (ready-for-agent)` | 명세 완료, AFK 에이전트가 가져갈 준비  |
| `ready-for-human`          | `사람 작업 준비 (ready-for-human)` | 사람 손이 필요한 작업                  |
| `wontfix`                  | `처리 안 함 (wontfix)`            | 처리하지 않을 이슈                       |

스킬이 한 역할을 언급할 때, 이 표의 라벨 문자열을 그대로 쓴다.
