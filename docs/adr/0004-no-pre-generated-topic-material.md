# 학습 자료는 미리 만들지 않음, 적시 생성만

초기 셋업은 `scripts/scaffold_topic.py` 로 학습 단위 자리표시자 (placeholder) — 학습 자료 (Topic material), 학습 코드 (Implementation artifact), 풀이 코드 (Solution artifact) 의 최소 슬롯 — 만 생성한다. 학습 단위가 실제로 공부되기 전엔 어떤 학습 콘텐츠도 만들지 않는다. 1개월 분량의 베스트셀러식 노트를 미리 다 쓰는 방안은 거절했다. 그렇게 만든 대량 자료는 학습자가 도달했을 땐 이미 낡았거나 몰입을 끌어내지 못한다. 적시 생성 (just-in-time) 은 레포를 가볍게 유지하고, 학습자가 묻는 그 순간에 맞춘 자료를 만들어낸다. 비용은 신규 학습자가 커리큘럼 콘텐츠를 미리 읽을 수 없다는 것 — 세션 (Session) 이 실제로 돌아가야 자료가 나온다. AI-guided 학습 시스템의 전제와 일치한다.
