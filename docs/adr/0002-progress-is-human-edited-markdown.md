# 진행 상태는 사람이 편집하는 마크다운, 구조화 데이터 아님

`docs/PROGRESS.md` 는 현재 학습 상태의 단일 진실 원천 (source of truth) 이며, 학습자와 AI 튜터가 세션 (Session) 마감 시에 직접 읽고 쓴다. JSON 이나 YAML 이 스키마 측면에서 더 유리하지만, 이 파일은 마감 과정의 일부로 인라인 편집되기 때문에 마크다운이 더 가볍고 grep 도 잘 되고 렌더러 없이 diff 로 검토 가능해서 선택했다. 진행 상태 뷰 (Progress view) 가 이 파일을 로드 시점에 파싱한다 (ADR-0003 참조). 마크다운 테이블과 라벨드 리스트 두 형태 모두 받는 비용은 뷰의 파서 안에 한정되며 단일 진실 원천 쪽엔 영향이 없다.
