# 학습 단위는 커리큘럼 멤버십과 분리, 즉흥 학습 단위도 1급 시민

학습 단위 (Topic) 는 슬러그로 식별되는 어떤 CS 학습 단위든 될 수 있으며, 커리큘럼 (Curriculum) 항목일 필요는 없다. 학습자가 계획된 1개월 경로 밖의 CS 지식 (예: TCP/UDP, 가비지 컬렉션) 을 물어볼 때, 즉흥 학습 단위 (Ad-hoc Topic) 가 생성되고 계획된 학습 단위와 똑같이 학습 자료·학습 코드·풀이 코드·진행 상태 기록을 받는다. 모든 학습 가능한 개념을 `docs/CURRICULUM.md` 안으로 우겨넣는 방안은 거절했다. 실제 학습은 곁가지를 포함하며, 커리큘럼은 1개월 운영 모델로서 초점이 유지돼야지 모든 학습 단위의 레지스트리가 되면 안 된다. `docs/CURRICULUM.md` 는 계획된 학습 단위 목록이고, `docs/PROGRESS.md` 가 계획·즉흥을 모두 포함한 활성 학습 단위 전체의 레지스트리다.
