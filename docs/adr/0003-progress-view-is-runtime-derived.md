# 진행 상태 뷰는 런타임 파생, 빌드 산출물 아님

`docs/progress.html` 은 `docs/PROGRESS.md` 를 로드 시점에 가져와 렌더링한다. 빌드 단계나 생성된 산출물은 없다. 페이지 자체엔 학습 상태가 보관되지 않으며, 스크립트 안의 의도된 self-test 가 이를 검증한다. 정적 사이트 제너레이터 방식은 진행 상태의 두 번째 표현을 만들어 동기화 부담을 키우기 때문에 거절했다. 서버를 띄우는 방식도 거절했다 — 목표는 학습자가 로컬에서 열 수 있는 파일이기 때문이다. 알려진 비용은 `file://` 접근에서 일부 브라우저가 `fetch` 를 차단할 수 있다는 점이며, 이 경우 명시적 폴백이 `PROGRESS.md` 로 안내한다. 데이터를 임의로 만들어내지 않는다.
