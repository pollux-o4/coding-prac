# coding-prac

`coding-prac` is the entry point for a one-month, AI-guided CS interview-prep
learning system. Python is the primary language for practice and examples.

Start with the stable learning docs:

- [Curriculum](docs/CURRICULUM.md): the planned learning sequence.
- [Learning flow](docs/LEARNING_FLOW.md): how a learner and AI guide work
  through a topic.
- [Topic format](docs/TOPIC_FORMAT.md): the expected shape of topic learning
  material.
- [Progress source](docs/PROGRESS.md): the source of truth for learner
  progress.
- [Progress view](docs/progress.html): the local derived progress view
  entrypoint.

These docs are the durable learning-system entrypoints as the system is built
out.
