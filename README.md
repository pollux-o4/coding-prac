# coding-prac

`coding-prac` 은 한 달짜리 AI-guided CS 면접 대비 학습 시스템의 진입점이다. 학습과 예제의 주 언어는 Python.

학습용 안정 문서는 여기서 시작한다.

- [커리큘럼](docs/CURRICULUM.md): 계획된 학습 순서.
- [학습 흐름](docs/LEARNING_FLOW.md): 학습자와 AI 튜터가 한 학습 단위 (Topic) 를 어떻게 진행하는지.
- [학습 자료 포맷](docs/TOPIC_FORMAT.md): 학습 자료 (Topic material) 가 가져야 하는 형태.
- [진행 상태 문서](docs/PROGRESS.md): 학습 상태의 단일 진실 원천 (source of truth).
- [진행 상태 뷰](docs/progress.html): 로컬에서 보는 파생 뷰 (derived view) 진입점.

기여자·에이전트가 처음 들어왔을 때 빠르게 보는 입구는 따로 있다.

- [CONTEXT.md](CONTEXT.md): 이 레포의 도메인 용어 사전.
- [docs/adr/](docs/adr/): 굳어진 결정의 짧은 기록.
- [docs/agents/artifact-map.md](docs/agents/artifact-map.md): "무엇을 어디에 저장하는가" 30초 라우팅 표.

이 문서들은 시스템이 확장되어도 유지되는 학습 시스템 진입점이다.
